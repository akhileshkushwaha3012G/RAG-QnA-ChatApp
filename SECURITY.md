# Security Policy

If you discover a security vulnerability in this project, please report it privately
and promptly so we can address it. Do not create a public issue for security
vulnerabilities.

Reporting
- Contact: [INSERT SECURITY CONTACT EMAIL]
- If possible include: steps to reproduce, a short description of impact, and any
  suggested fixes or mitigations.

Response
- We will acknowledge receipt within 72 hours and provide updates as we work on a
  fix.

Disclosure policy
- Please allow a reasonable period for contributors to fix the issue before public
  disclosure. We will coordinate timelines with the reporter if needed.
